Manual & FAQs

How it works

1. Setup: Open from your Mac menu bar or Windows system tray.

2. Set the Time: Type your reminder and pick when it should fire.

3. The Smash: Hemulky drops onto your screen with the message.

Install

Mac: Download HemulkyReminder-Mac.zip, unzip, then right-click Install Hemulky.command → Open. Do not open the .app first.

Windows: Run HemulkyReminder-Setup.exe, then find Hemulky in the tray.

If Windows SmartScreen blocks it: More info → Run anyway.

If Mac still moves the app to Trash, run: xattr -cr /Applications/HemulkyReminder.app && open /Applications/HemulkyReminder.app

Controls

ESC Dismiss Hemulky anytime.

Click Click the screen to close the reminder.

Hulk Looks

Classic, Gray, Professor, or Smash — pick a look before you set a reminder.

FAQs

Is it free?

Yes — 100% free, no ads.

Does it work on Windows?

Yes. Use the Windows installer for Windows 10+, or the Mac DMG for macOS 12+.

Recurring reminders?

Yes — use Repeat Every in the tray controls.
