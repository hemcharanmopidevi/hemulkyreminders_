Mac install (avoid “malware” block)

  1. Download HemulkyReminder-Mac.zip and unzip it.
  2. Right-click Install Hemulky.command → Open → Open.
  3. Do not double-click the .app first — the installer clears macOS quarantine for you.
  4. Hemulky appears in the menu bar (top right).

Without an Apple Developer certificate, macOS may still warn once on the installer script — choose Open. That is normal for local apps.

Still blocked?

Restore from Trash, then run in Terminal:

xattr -cr /Applications/HemulkyReminder.app
open /Applications/HemulkyReminder.app

Windows: SmartScreen → More info → Run anyway.
